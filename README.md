# Netflix Content Strategy Analyzer

## Project Overview
This project analyzes the Netflix Titles dataset through four milestones, covering data preprocessing, exploratory data analysis, machine learning, and an interactive dashboard.

## Milestone 1 – Data Cleaning & Preprocessing
- Loaded the Netflix dataset
- Handled missing values
- Removed duplicates
- Cleaned and standardized the data

## Milestone 2 – Exploratory Data Analysis (EDA)
- Movies vs TV Shows distribution
- Release year analysis
- Country-wise content analysis
- Genre analysis
- Interactive visualizations

## Milestone 3 – Machine Learning
- Feature engineering
- Content clustering
- Classification model
- Feature importance
- Confusion matrix

## Milestone 4 – Interactive Dashboard
Developed a Streamlit dashboard with:
- Interactive sidebar filters
- Strategic Catalog Insights
- AI Analytics
- Cluster visualization
- Feature importance visualization
- Confusion matrix
- Interactive Movie/TV Show prediction

## Technologies Used
- Python
