# Netflix Analytics Dashboard

## Project Overview

This project analyzes the Netflix Titles dataset using Python, Machine Learning, and Streamlit.

## Features

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Classification Model
- Clustering Model
- Interactive Dashboard
- Feature Importance Visualization

## Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Streamlit
- Scikit-learn
- Matplotlib
- WordCloud

## Files

- milestone1.py – Data Cleaning
- milestone2.py – Exploratory Data Analysis
- milestone3.py – Machine Learning
- milestone4.py – Streamlit Dashboard

## Dataset

Netflix Titles Dataset

## How to Run

```bash
streamlit run milestone4.py
```
